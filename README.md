# QA API Testing Lab

🚧 **Proyecto en construcción**

Laboratorio de pruebas automatizadas de APIs. El objetivo es diseñar casos de prueba, automatizarlos, encontrar bugs y documentarlos como se hace en un trabajo real de QA.

## Stack

- Python 3
- pytest
- requests
- GitHub Actions (CI)
- SQL para validación de datos (fase 3)

API bajo prueba: [Restful-booker](https://restful-booker.herokuapp.com/)
